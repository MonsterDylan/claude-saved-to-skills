# demo-reel-plan: verdict

**Keep, with a trim.** Tested 2026-11-10, one task, one run each way.

## Task

Plan a reel about the Telegram bridge (text a bot, Claude runs in the vault and replies). The creator's own system, not a topic from the source reels.

## What the skill changed

Every difference below traces to a rule in the skill.

| Decision | Without the skill | With the skill | Rule |
|---|---|---|---|
| First 3 seconds | Selfie, claim to camera | The text being typed and sent | Start mid-action, +20 |
| Face during the demo | Gone. Full-screen phone, then phone over terminal | Stays in the lower panel start to finish | Face in frame, +16 |
| The sleep timeout | A spoken "one catch" right before the ask | A shown failure and fix at the 40 percent mark | Friction in the demo, +12 |
| Mac screens | Screen recorded | Filmed by hand with the phone, finger pointing | Phone-filmed screen, +8 |
| The ask | Cut back to selfie | Same split shot, keyword pinned as a label | Face-for-the-ask, -25 |
| The guide | Mentioned at the end | Flashed at the fix, mid-reel | Deliverable before the ask, -16 |
| Graphics | Eight text overlays, "fast and dense" | Three, each justified. The rest left raw | Visual per noun, -23 |
| Length | Not stated | 65 seconds, with the wait run in real time | Length finding |

It also listed three places the evidence disagrees with the creator's own rules and left the choice to him.

## What the baseline already did

- Proof-led framing, a late "craziest part" beat, one keyword as the last line.
- A filmable capture plan and an honest rule about not speeding up the wait.
- The warning about client names and secrets on screen.

## Where the baseline was better

- It added a caption, a giveaway outline, a delivery message, a pinned comment and test variations. Useful, and the skill's fixed format left them out.
- It raised locking the bot to your own account. A real point the skill run missed.
- The skill run spent about 400 words restating evidence.

## Changes made to the skill

1. Evidence section capped at 8 lines, only rules that changed a decision.
2. Added a "Before filming" privacy check to the output.
3. Added one line offering caption and giveaway work as separate jobs.

## Not verified

Whether the with-skill plan performs better. The skill makes the plan follow the collection's evidence. That evidence is correlation in 66 reels. Filming both versions is the only real test. The trimmed skill has not been re-run.
