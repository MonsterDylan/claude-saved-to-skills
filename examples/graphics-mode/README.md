# Graphics mode: example run

Seven graphics-heavy reels, run through graphics mode.

- 78 on-screen graphics read from burst strips
- 28 effects in the catalog: 19 new to me, 9 I already had

| File | What it is |
|---|---|
| [effects-catalog.md](effects-catalog.md) | Every effect, how it moves, and how to rebuild it |
| [style-sheets.md](style-sheets.md) | One style sheet per creator: zones, type, captions, rhythm, restraint |
| [effects.json](effects.json) | The cluster map the catalog is built from |
| [sample-graphics-card.json](sample-graphics-card.json) | One reel's full graphics card |

Two notes:

- The burst strips themselves are not in this repo. They are frames of other creators' videos. Your own run writes them to your machine.
- "You have" and "closest you have" in the catalog refer to my own effects library, [claude-video-effects](https://github.com/MonsterDylan/claude-video-effects). On your run they refer to yours, if you have one.
