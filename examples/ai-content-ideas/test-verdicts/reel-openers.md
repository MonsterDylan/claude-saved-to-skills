# reel-openers: verdict

**Trim, then keep.** Tested 2026-11-10, one task, one run each way.

## Task

Hooks for a reel about the "dream cycle" (Claude tidies an Obsidian vault at 3:30am). The creator's own system, not a topic from the source reels.

## What the skill changed

- **Selection.** With the skill, 3 of 5 openers start mid-action and the pick is a mid-list open over the terminal log. Without it, the pick is a plain claim to camera and mid-action is not a stated priority.
- **First frame.** With the skill, the face sits in a panel under the log. Without it, the log runs full screen and cuts to the face.
- **Exclusions.** With the skill, opening on the system's name, news framing, a profession callout and a pop-culture reference are each ruled out with the evidence. Without it, one option opens on the name ("I call it the dream cycle").
- **Ranking with reasons.** With the skill, every option cites its lift and creator count.

## What the baseline already did

- Gave spoken line, on-screen text and visual for every hook. The skill's "an opener is three things" teaching added nothing.
- Used only the given numbers and flagged client names on screen. (Both runs were told not to invent numbers, so that rule is untested.)
- Led with the result on screen.

## Where the baseline was better

- **Range.** 14 hooks against 5, and several baseline lines have more personality: "I gave Claude a night shift", "My second brain dreams now". The skill's fixed "give 5" narrowed the output.

## Changes made to the skill

1. Draft at least 12 freely first, then rank against the evidence. The evidence filters, it does not shape the writing.
2. Added a "Worth keeping" list for strong unranked lines and a "Cut, and why" list.
3. Cut the "three things" teaching and the wording rules that belong to the user's own voice skill.

## Not verified

Whether the skill's pick outperforms the baseline's pick. Only posting both would show that. The trimmed skill has not been re-run.
